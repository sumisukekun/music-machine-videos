Privacy Policy / プライバシーポリシー

Last updated: 2026-11-03

Data we access

When the operator authorizes the Service with TikTok, we receive an access token and refresh token for that single account, plus basic profile information (open ID, display name, avatar) and the creator's posting options returned by TikTok.

How we use it

The tokens are used only to publish videos created by the Service to the authorizing account and to read the creator's privacy options. They are stored encrypted as repository secrets and are never shared or sold.

Data of other users

The Service does not collect, store, or process any data about other TikTok users or viewers.

Retention and deletion

Tokens are kept only while authorization is active. Revoking access in TikTok settings, or asking the operator, removes them.
